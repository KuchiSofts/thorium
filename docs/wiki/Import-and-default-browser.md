# Import and default browser

This page describes the first run from the first release. Both steps are offers. Nothing is taken over
silently, and declining leaves everything as it was.

## Import

On first start Thoron looks for other browsers on the PC and offers to bring over:

- bookmarks, history and saved passwords;
- cookies, so you stay signed in;
- extensions and settings;
- open tabs and tab groups, with their names and colours.

Thoron copies. It never moves or changes the data of the other browser, and it asks you to close that
browser first so the copy is complete.

## Default browser

Thoron can open web links and the file types a browser opens, such as HTML and PDF files. Windows 10 and 11
want you to confirm a default browser yourself, so Thoron opens the Windows page for it.
