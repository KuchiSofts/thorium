# Thoron

Thoron is a fast, secure and private browser for Windows. It is based on
[Thorium](https://github.com/Alex313031/thorium) and Chromium, and it is an independent project by KuchiSofts.

**Status:** there is no public release yet. The first one is **Thoron 0.1.1 for Windows x64**. What is left
before it is at the top of the [roadmap](https://github.com/KuchiSofts/thoron/blob/main/ROADMAP.md).

## What Thoron promises

- **Your data stays yours.** An update or an import never deletes, moves or changes your profile. No telemetry.
- **Signed updates.** The browser refuses an update that is unsigned, altered or older than what you have.
- **Fast security fixes.** The target is 7 days after a Chrome release that fixes an actively exploited bug.
- **Open source.** What a release is built from is in the repository, and anyone can check it.
- **Full credit.** Everyone whose work Thoron builds on is named in
  [CREDITS.md](https://github.com/KuchiSofts/thoron/blob/main/CREDITS.md).
