# Building from source

What a release is built from is in the repository.

- The browser's own changes are in
  [`source/`](https://github.com/KuchiSofts/thoron/tree/main/source): a patch series on one pinned upstream
  commit, with a hash anyone can verify.
- The build guide for Windows 11 is
  [docs/build/WINDOWS.md](https://github.com/KuchiSofts/thoron/blob/main/docs/build/WINDOWS.md).
- The repository's own tools need only Python 3.11 or newer.

A full build of Chromium takes a few hours and about 250 GB of disk space.
