# Versions

Thoron has its own version numbers: `0.MINOR.PATCH`. The first release is **0.1.1**, and every release gets
the next number.

- The **About page** shows the Thoron version (now **0.1.1**) and, below it, the Chromium version it is
  built on. `chrome://version`, `chrome://flags` and the Windows list of apps show it too.
- The [changelog](https://github.com/KuchiSofts/thoron/blob/main/CHANGELOG.md) lists what changed in each
  version, one line per change.
- Websites and extensions see the Chromium version, as they expect.
