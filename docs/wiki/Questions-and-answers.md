# Questions and answers

**Is Thoron the same as Thorium?**
No. Thoron is an independent browser by KuchiSofts. It is based on Thorium and Chromium and credits both.

**Will an update change my data?**
No. An update only replaces the program. See [Updates](Updates).

**Do my Chrome extensions work?**
Yes. Thoron runs Chromium extensions, including Manifest V2 ones.

**Can I use it next to Thorium or Chrome?**
Yes. Thoron has its own folder and its own profile and does not touch another browser.

**Where do I report a bug?**
In the [issues](https://github.com/KuchiSofts/thoron/issues). A security problem goes through
[private reporting](Privacy-and-security#report-a-vulnerability) instead.

**Which platforms?**
Windows x64 first. Ubuntu and ARM64 later.
