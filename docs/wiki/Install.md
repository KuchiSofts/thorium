# Install

There is no public release yet. This page describes how installing works from the first release,
Thoron 0.1.1 for Windows x64.

## Windows

1. Download `ThoronSetup.exe` from the newest [release](https://github.com/KuchiSofts/thoron/releases).
2. Run it. It downloads the newest version of Thoron, checks its signature and installs it.

Good to know:

- It installs for your user account. No administrator rights are needed.
- The same `ThoronSetup.exe` always installs the newest release, so you never need a newer copy of it.
- Every release also has the full installer, for a PC without a network.
- On first start Thoron offers to [import from your other browser](Import-and-default-browser).

Windows may warn about an unknown publisher: the installer has no paid code signing certificate yet. You can
check a download yourself with the signed `SHA256SUMS` file of the release, as the
[README](https://github.com/KuchiSofts/thoron#verifying-downloads) shows.

## Other platforms

Windows comes first. Ubuntu and ARM64 follow once Windows releases run smoothly.
